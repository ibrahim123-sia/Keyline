# Lintel

AI-powered website, CRM and lead engine for real estate agencies. One agency installs it and runs its whole business from it.

The full specification lives in [`lintel-spec/lintel-spec`](lintel-spec/lintel-spec/README.md). Build progress is tracked in [`PROGRESS.md`](PROGRESS.md).

## Requirements

- Node.js 22+ (developed on Node 24)
- pnpm 12

## Quick start

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

More setup steps (database, seed data, Cloudflare deploy) are added as each phase lands.
