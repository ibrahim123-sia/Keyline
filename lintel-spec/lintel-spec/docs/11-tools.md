# 11 — Buyer and Investor Tools

Each tool is a public page, a reusable component (used on property pages), and an AI tool with the same maths. All maths lives in one tested module (`/features/tools/math.ts`) with unit tests.

## 1. Mortgage calculator (`/tools/mortgage`)
- Inputs: property price (prefilled on property pages), down payment (% or amount, slider), loan term (years), interest rate, optional fees (registration %, agency %, mortgage arrangement %)
- Outputs: monthly payment, loan amount, total interest, total cost, upfront cash needed (down payment + fees), amortisation chart by year
- Limits from settings (max loan-to-value, max term)
- Clear note: "Estimate only. Your bank will confirm the final numbers."
- CTA: **Get pre-approved** → form (name, phone, email, monthly income band, employment type, down payment ready yes/no) → lead source `mortgage`
- Share link with inputs in the URL

## 2. Rental return / ROI simulator (`/tools/rental-returns`)
- Inputs: purchase price, purchase costs %, long-term yearly rent **or** short-term mode (nightly rate high/low season, occupancy % 50–90, management fee % 15–25), service charge per area unit × size, maintenance %, vacancy %, mortgage on/off (uses mortgage inputs), yearly rent growth %, yearly price growth %
- Outputs: gross yield, net yield, yearly net cash flow, 5-year and 10-year table (cash flow, equity, total return), IRR %, break-even year
- Chart: cumulative cash flow and equity over 10 years
- Assumptions box with plain-language notes; defaults from settings
- CTA: **Email me this report** → PDF report → lead source `roi`
- On property pages: prefilled from `price`, `size`, `expected_rent_yearly`, `service_charge_per_area`

## 3. Compare (`/tools/compare`)
- Up to 4 properties (or project unit types)
- Add from any card ("Compare" checkbox) → floating compare tray at the bottom with thumbnails and "Compare (3)"
- Table rows: photo, price, price per area, purpose, completion, type, beds, baths, size, area, handover, payment plan label, service charges, expected yield, nearest school / metro / mall (from POIs), facilities (✓/–), verified date, agent
- Highlight best value per row (lowest price per area, highest yield, nearest school)
- Guests: stored in local storage; customers: saved to account (`compare_sets`)
- Share link and "Send to my email"

## 4. Branded PDF brochure (1 click)
- Button on property and project pages, and in admin
- Generated by Cloudflare Browser Rendering from an HTML template that uses branding tokens
- 4 pages: (1) cover photo, title, price, key facts, logo; (2) gallery grid + description; (3) floor plan + facilities + payment plan table; (4) map with POIs and distances + agent card (photo, phone, WhatsApp QR, email) + permit number + reference
- Cached in R2 per listing version; regenerated when the listing changes
- Optional email gate (setting) → lead source `brochure`
- File name: `[reference]-[slug].pdf`

## 5. Free valuation (`/valuation`)
- Steps: (1) purpose sell or rent, (2) location and building, (3) type, beds, baths, size, condition, upgrades, (4) photos (optional), (5) contact details
- Result screen: estimated range (low – high) from comparable own listings, with the comparables shown ("Based on 6 similar homes in Dubai Marina"), plus "An agent will refine this within 24 hours"
- If fewer than 3 comparables: no number, message "We need a quick look to value this one", agent task created
- Lead source `valuation`, creates `valuation_requests` row, notifies the area's agent

## 6. List your property (`/list-your-property`)
Same steps as valuation without the estimate, plus asking price and available from. Creates `listing_requests` + lead (type seller or landlord). Admin can convert a request into a draft listing in one click.

## 7. Price trends (area pages and property pages)
- Chart: median price per area unit by month, for sale and rent, per location (and type where there is enough data)
- Data sources (labelled on the chart):
  1. **Agency data:** computed monthly by a cron job from the agency's own listings and closed deals (`area_price_stats`, source `agency_data`)
  2. **Admin-entered data:** the admin can add monthly figures with a source note (e.g. from a public market report), source `admin_entered`
- Show "Not enough data yet" when fewer than 5 data points
- Also show: listings count, average days on market, change vs 12 months ago

## 8. Draw-your-own-area map search
- On the search map: "Draw your area" → freehand or point-by-point polygon (MapLibre draw)
- The polygon is simplified, encoded in the URL (`poly=`), and used in SQL with `ST_Within(point, polygon)`
- Edit or clear the drawing; customers can save it with a saved search
- Works on touch screens

## 9. Commute time search
- "Commute time" filter: pick a place (from POIs, autocomplete, or any address via geocoding), travel mode (drive / walk), max minutes (5–60)
- Implementation (cost-safe): for agency POIs, use stored `property_pois` drive/walk times. For any other place, call Google Routes **once** to compute a travel-time matrix from that place to the active listings in the current bounds (batched, cached by place + mode for 7 days), then filter
- Shows the time on each result card ("18 min drive to [place]")
- If the API is unavailable, fall back to straight-line distance with a clear label

## 10. Dynamic share cards
- Route `/og/property/[slug]` returns a 1200×630 image: cover photo, price in base currency, beds / baths / size, area name, verified badge, agency logo
- Same for projects, area guides and posts
- Used as `og:image` and `twitter:image`; cached and regenerated when the content changes
- WhatsApp, Facebook, LinkedIn and X previews checked in the SEO panel preview

## 12. Verified listing badge
- Admin marks a listing verified after an in-person check; `last_verified_at` set; badge shows "Verified [date]"
- Badge disappears automatically when verification is older than the setting (default 30 days) and the listing shows in "Needs verification"
- Public "How we verify" page (CMS) linked from the badge tooltip
